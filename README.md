# 📰 Odisha E-Paper

Automated daily downloader and Telegram publisher for major Odisha newspapers.

### Newspapers

- 📰 Samaja
- 📰 Sambad
- 📰 Dharitri
- 📰 Pragativadi
- 📰 Prameya

### Features

- 📥 Automatic daily e-paper downloads
- 📄 PDF generation and compression
- 🔄 Retry support for unavailable editions
- 🛡️ Duplicate protection with state tracking
- 🔐 SHA-256 verification
- 🤖 Automatic Telegram publishing
- ⚙️ GitHub Actions automation
- 🧹 Monthly Actions cleanup
